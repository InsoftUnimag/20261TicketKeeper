# Hola Mundo con Spring Boot

Proyecto web desarrollado con Spring Boot que permite al usuario ingresar su nombre mediante una interfaz gráfica.

## Funcionalidad

El usuario ingresa su nombre en un formulario HTML y el sistema responde con un saludo personalizado.

##  Endpoint

GET /saludo-final?nombreUsuario=Sebastian

##  Interfaz

El proyecto incluye una página HTML con estilos CSS para mejorar la experiencia del usuario.

## Tecnologías

- Java
- Spring Boot
- Maven
- HTML + CSS
