# Error codes

| Codigo | Significado |
| --- | --- |
| `LECTOR_NO_CONFIGURADO` | El lector no tiene configuracion valida para operar. |
| `TICKET_NO_ENCONTRADO` | El ticket solicitado no existe o no esta disponible. |
| `ESTADO_INVALIDO` | El estado actual del ticket no permite la operacion. |
| `SESION_INVALIDA` | La sesion no corresponde o no esta habilitada. |
| `ZONA_INCORRECTA` | El ticket o la puerta no corresponden a la zona esperada. |
| `TICKET_DUPLICADO` | El ticket ya habia sido utilizado para el mismo flujo. |
| `EVENTO_NO_ENCONTRADO` | No existe el evento consultado. |
| `ASIGNACION_CONFLICTIVA` | La asignacion de puerta entra en conflicto con otra existente. |
| `REINGRESO_NO_PERMITIDO` | El ticket no tiene permiso de reingreso. |
| `LIMITE_REINGRESO_EXCEDIDO` | Se alcanzo el maximo de reingresos permitido. |
| `SALIDA_NO_PERMITIDA` | No se puede registrar la salida en el estado actual. |
| `ERROR_TECNICO` | Ocurrio un error interno no funcional. |
